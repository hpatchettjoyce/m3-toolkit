Source: page 15, "MONUMENTUM — COLOR PALETTE". **Every one of the 18 swatches has an RGB value that
matches its printed hex exactly (18/18)**, so these values are read from the guide, not sampled.

naming the CSS tokens.

## What this gives Chunk 6

- **The off-black ground the chunk asks for is `#041212` (OFF-BLACK).** `#374141` and `#999F9F` are
  the natural panel and border steps above it; `#F8F3E6` (OFF-WHITE) is the body text colour.
- `#E4A557` (GOLD STONE) is the obvious accent — it is the only high-chroma, high-luminance colour
  in the set and reads well on the off-black.

## Open question for Harvey — dominion colours

**The guide gives four chromatic hues (wine, gold, green, teal) but the game has six dominions**
(`01RHA` Rhavlika, `02IRO` Iro-Si-Khar, `03VOI` Voisira, `04XAL`, `05AHE` Ahèserec, `06VER`). The
current `FACTION_COLORS` in the frontend has six entries (`#c0392b`, `#2980b9`, `#b7950b`, `#7d3c98`,
`#27ae60`, `#138d75`).

So the guide does **not** specify a dominion mapping, and Chunk 6's "re-map `FACTION_COLORS` to the
brand's dominion colours *if the guide specifies them*" resolves to: it doesn't. Two ways forward,
and this is Harvey's call:

1. **Keep six distinct hues**, deriving the two extras by extending the brand's own hue logic. Keeps
   dominions visually separable, which matters — these colours are also the low-ink print borders.
2. **Use the four brand hues** and distinguish the remaining two dominions some other way.

Do not guess this: the colours carry meaning in play.

## Reading the PDF on this machine

There is **no PDF tooling installed**: no `poppler-utils` (so no `pdftotext`, and Claude's PDF page
rendering fails with "pdftoppm is not installed"), no `pypdf`, no `pip`, and `apt-get` needs a sudo
password. `extract_brand_palette.py` works around this by inflating the PDF's own content streams
with `zlib` — no dependencies.

To read the guide *visually* (needed for layout, logo placement and Chunk 7), install:

```bash
sudo apt-get install -y poppler-utils
```

**Trap:** a bare `#[0-9A-Fa-f]{6}` regex over the inflated streams also matches byte sequences inside
the embedded font programs and invents colours that are not in the brand — `#532677` (a purple),
`#526557` and `#566557` all appear that way. The extractor anchors on the full `RBG:/CMYK:/HEX:`
triple the guide prints beside each swatch, which is why it returns exactly 18.
